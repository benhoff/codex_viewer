Recommended starting limits: 20,000 input characters, 512 output tokens, 600 seconds. Requests also respect a 32,768-token context budget covering instructions, schemas, evidence and output. A conservative UTF-8 byte estimate can split multilingual evidence sooner. Thinking is disabled on every request; incomplete or invalid JSON fails grading.

Enabling external processing allows reviewers to send selected evidence to this endpoint. Large inputs use up to 100 sequential evidence batches, followed by a whole-task assessment and one configuration request. Additional summary calls combine evidence when needed. Images and audio are explicitly marked unavailable and never sent as encoded text. Only one grading run is admitted per viewer process. Timeout or Cancel aborts the active HTTP request; retries require an explicit action.

Saved changes apply to the next grading run. No restart is needed.

The chart uses estimated ordinal capability levels 1–5. It cannot establish a percentage of excess intelligence, measured savings, or faster completion. Controlled reruns are needed for those comparisons.
